Khóa Học Online Cho Trẻ Em - CMC Kids Learning

- Chào mừng bạn đến với nền tảng Khóa Học Online Cho Trẻ Em! Nền tảng được thiết kế nhằm mang đến trải nghiệm học tập thú vị và bổ ích cho trẻ em mọi lứa tuổi. Với các bài học tương tác, bài kiểm tra và hoạt động thúc đẩy, trẻ có thể khám phá nhiều môn học và phát triển kỹ năng cần thiết.
- Tính Năng
Bài Học Tương Tác: Nội dung hấp dẫn phù hợp với từng độ tuổi.
Học Linh Hoạt: Truy cập bài học mọi lúc, mọi nơi.
Môi Trường An Toàn: Nền tảng thân thiện với trẻ em, không quảng cáo.
Theo Dõi Tiến Trình: Giúp bạn theo dõi thành tích học tập của trẻ.

Cài Đặt và Thiết Lập

Clone repository này về máy của bạn:
- git clone https://github.com/Vutien12/CMC_Kids_Learning.git
Di chuyển đến thư mục dự án:
- cd online-course-for-kids
Cài đặt các phụ thuộc:
- npm install
Chạy server phát triển:
- npm start
Mở trình duyệt và truy cập để vào nền tảng.

Hướng Dẫn Sử Dụng
Đăng Ký: Phụ huynh tạo tài khoản cho trẻ.
Duyệt Khóa Học: Khám phá các môn học như Toán, Tiếng Việt, Tiếng Anh v.v.
Đăng Ký Khóa Học: Chọn và tham gia khóa học phù hợp với sở thích của trẻ.
Học và Chơi: Hoàn thành bài học, làm bài trắc nghiệm và tham gia trò chơi tương tác.
Theo Dõi Tiến Trình: Xem báo cáo hiệu suất và thành tích.
